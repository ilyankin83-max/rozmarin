# Блок расчёта кухни

`index.html` — отдельный предпросмотр без шапки сайта. Кнопка открывает демонстрационное окно. Это вёрстка приглашения к расчёту, а не новый калькулятор: расчёт цены и формы из действующего сайта сюда не переносились.

- `block.html` — только блок для вставки на главную.
- `style.css` — адаптивные изолированные стили и оформление необязательного native dialog.
- `script.js` — открытие/закрытие native dialog без сторонних библиотек, Escape, возврат фокуса, закрытие по фону.
- `images/kitchen.webp` — фото из согласованного макета, 666×550. Для экранов высокой плотности можно заменить более крупным оригиналом.

## Подключение

1. Перенесите папку в `/local/templates/ВАШ_ШАБЛОН/kitchen-calculator/`.
2. Подключите style.css и script.js через Asset::getInstance()->addCss()/addJs() либо обычные link/script в вашем шаблоне.
3. Вставьте block.html вместо старого выбора типов мебели. Замените src фотографии на абсолютный путь в шаблоне сайта. `skiplazy` сохраняет src при вашем обработчике init.php; используется нативная ленивая загрузка.
4. Выберите один вариант подключения окна ниже. Не публикуйте демонстрационный текст из index.html.

### Вариант A: native dialog

Перенесите элемент dialog из index.html рядом с блоком. Замените демонстрационный абзац действующей формой/калькулятором. Сохраните id="kitchen-calculator-popup", кнопку закрытия и заголовок. Выполните существующую инициализацию калькулятора; при необходимости пересчитайте размеры после открытия. В одном документе используйте один dialog с этим ID.

### Вариант B: существующий Fancybox или другое окно

Сохраните существующую разметку и обработчик вашего калькулятора. Замените атрибуты кнопки в block.html на атрибуты его штатной кнопки открытия; удалите data-kitchen-open и обновите aria-controls под реальный ID. Наш script.js тогда не нужен. Не подключайте два обработчика открытия одновременно.

Либо обработайте событие `rm:kitchen-open` на document, вызовите event.preventDefault() и откройте существующий калькулятор вашим API. В event.detail передаются id и trigger. Адреса, селекторы и версия вашего действующего калькулятора неизвестны, поэтому привязка к нему не выдумана.

На десктопе — текст слева, фото справа. До 760px — фотография над текстом. В блоке нет внешних шрифтов, сетевых библиотек, форм отправки или аналитики.
