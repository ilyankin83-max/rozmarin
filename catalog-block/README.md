# Блок каталога «Розмарин»

Откройте index.html для просмотра. block.html — фрагмент для главной страницы, style.css — изолированные стили. JavaScript и внешние библиотеки не нужны.

## Установка в Bitrix

1. Перенесите папку catalog-block в шаблон сайта, например /local/templates/ВАШ_ШАБЛОН/catalog-block/.
2. Подключите style.css через Bitrix\Main\Page\Asset::getInstance()->addCss(SITE_TEMPLATE_PATH . '/catalog-block/style.css').
3. Вставьте содержимое block.html вместо прежнего блока. Замените относительные src="images/…" на адреса /local/templates/ВАШ_ШАБЛОН/catalog-block/images/… .
4. Проверьте и замените ВСЕ href на фактические адреса разделов. URL в демо — предполагаемые, особенно individualnye, na-zakaz и modulnye; структура новых подразделов на сайте не подтверждена.

Класс skiplazy сохраняет обычный src при обработке изображений регулярным выражением в init.php. Используется нативный loading="lazy". Основные названия — h3, заголовок блока — h2. Ссылки на подразделы самостоятельные, вложенных ссылок нет. Фото дублирует ссылку заголовка, поэтому исключено из клавиатурного порядка и дерева доступности.

## Изображения и адаптивность

Восемь отдельных WebP вырезаны из согласованного дизайн-макета. Исходный размер каждого 340×271; для больших экранов можно заменить их оригинальными фотографиями 680×542 и выше. Изображения — иллюстрации макета, не подтверждённые фотографии выполненных проектов.

Четыре колонки на десктопе, две при ширине до 1000 px. На невысоких десктопах фото компактнее. На телефоне блок прокручивается вместе со страницей: восемь категорий с читаемыми пояснениями не помещаются в один небольшой экран. Горизонтальной прокрутки и слайдера нет.
